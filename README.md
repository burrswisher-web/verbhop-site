# verbhop.com

The website for Verb Hop, served by GitHub Pages from `main` at the root.

- `index.html`: home page (to be replaced by the Claude Design export; keep its links to the two pages below)
- `privacy.html`: the privacy policy, linked from Google Play
- `terms.html`: the terms of use
- `site.css`, `assets/`, icons: shared by the pages
- `CNAME`: the custom domain

Plain HTML that reads without JavaScript, so Google Play's reviewers and search engines can read the policy.
